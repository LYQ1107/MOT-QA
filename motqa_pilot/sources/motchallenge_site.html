MOTChallenge – Multiple Object Tracking Benchmark

This service is currently offline.

The MOTChallenge benchmark website is not in operation. The evaluation server, submissions and user accounts are offline.

The dataset archives remain available at their existing addresses. Download links published in papers and documentation continue to work unchanged.

The leaderboards have been preserved as a static archive. All published results (state of 16 April 2026) with method pages, per-sequence results, result videos, raw result files and a CSV export per benchmark. The former result and method addresses continue to work.

The directory is deliberately not browsable, so a file can only be retrieved under the exact name it was published with. If you need an archive whose name you do not know, please consult the paper or documentation that referred you here.
